# Carry On Only

**One bag, nothing extra.**

Сборы под лимит ручной клади. Приложение считает, сколько каждой вещи брать по
погоде, планам и стиркам, надевает самое тяжёлое на тебя, при перевесе находит
наименее болезненные урезания и учится после каждой поездки, сколько ты на самом
деле носишь. Полностью офлайн.

## Особенности

- Количество по циклам между стирками, полоса дней с погодой и стиркой жестами.
- Точная укладка в лимит (рюкзак с множественным выбором, сверено с перебором).
- Конфликты с проверенными выходами, what-if, «почему столько» по каждой вещи.
- Разбор после поездки → выученный множитель «дней носки» по каждой вещи.

## Запуск

```bash
npm install
npx expo start
```

## Проверки

```bash
npm run verify   # tsc + node --test + check-rules + expo export
```
